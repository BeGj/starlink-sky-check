# Goal
Primarily a webapp with no backend, but if not possible then a backend is acceptable

## User story:
My father has a cottage up in the woods. He has bad internet via mobile broadband. We are considering starlink. The cottage is on a hillside, so we dont know exactly how much of the sky is visible from the cottage.
He needs a tool to simulate having a starlink on his roof and see how much of the sky is visible.

## Techincal details
We need to generalize this tool so that anyone can use it to place a point on a map, set its height above the ground. (where the starlink antenna is).
Focusing only on norway, using norwegian height data. from f.ex. https://kartkatalog.geonorge.no/metadata/kartverket/hoydedata-laser/f297e948-8a34-4e6c-9740-54b3a657f8d5
Then we draw on the map "the viewline". Premade starlink templates (how much is requires 110 degrees i think).
